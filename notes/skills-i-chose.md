# Skills I chose

Searched skills.sh on 2026-11-14 with `npx skills find` for: email marketing, email sequence, campaign plan, resend. Then I looked up each publisher's GitHub repository. Nothing has been installed yet.

## Use these

1. **Anthropic's marketing plugin** (`anthropics/knowledge-work-plugins`), for planning and writing campaigns.
   - Made by Anthropic, the company behind Claude. The repository has about 35,700 GitHub stars and was updated this week.
   - It has the three skills this studio needs: `campaign-plan` (about 3.4K installs), `email-sequence` (about 3.1K) and `brand-review`.
   - Its install counts are lower than some other results, but the publisher is official and the star count is very high, so it's trustworthy.

2. **Resend's own skills** (`resend/resend-skills` and `resend/email-best-practices`), for sending email.
   - Made by Resend, the email service we connect in step 9, so they describe its tools correctly.
   - The `resend` skill has about 24.6K installs, `email-best-practices` about 8.3K. The repositories have 212 and 146 stars and were updated recently.

## Avoid these

1. **`caffeinelabs/skills@extension-email-marketing`**: about 31,300 installs but only **2 GitHub stars**. Tens of thousands of real users would leave far more stars than that, so the install count may have been inflated. The publisher is also unknown.

2. **`mbfinotti/partnerships-skills@joint-gtm-planning`**: about 16,600 installs but only **2 GitHub stars**. It's run by one person, and the numbers don't add up.

Also worth noting: `open.feishu.cn@lark-mail` has the most installs of all (about 892K), but it's for a different email app (Lark), not email marketing. A big number doesn't make a skill fit your job.

## How I decided

Three things to check before installing any skill:

1. **Who made it?** Prefer the official maker of the tool (like Anthropic or Resend) or a well-known publisher over an unknown account.
2. **Do the numbers agree?** Compare installs with GitHub stars. Lots of installs but almost no stars is a warning sign, because install counts can be faked.
3. **Is it alive and does it fit?** Check that the repository was updated recently and that the skill really does the job you need. A skill is instructions Claude will follow, so read what it does before you trust it.
